Proyecto next js para la materia de seguridad informatica

# Requisitos

- Node.js 18
- Mongodb 5.0
- npm o yarn
Para descargar todas las dependencias ya teniendo npm instalado:
npm install

# Iniciar
Para inicar la app, puedes utilizar el siguiente comando en una terminal estando en el directorio de la aplicacion
npm run dev
